2. T1 — BACKEND: FILTRO POR CUSTODIO EN GET /api/transactions
=============================================================================

Archivo: backend/app/routers/transactions.py

El endpoint GET "" ya acepta instrument_id, type, date_from, date_to.
Agregar parámetro adicional:

  custodian: Optional[str] = Query(None)

Implementación: si custodian está presente, hacer join con Instrument y filtrar:
  query = query.join(Instrument, Transaction.instrument_id == Instrument.id)
               .filter(Instrument.custodian == custodian)

IMPORTANTE: el join solo se agrega si custodian no es None, para no romper
consultas existentes.

Agregar también: month_year: Optional[str] = Query(None)
  Formato esperado: "YYYY-MM"
  Implementación:
    if month_year:
        query = query.filter(func.strftime('%Y-%m', Transaction.date) == month_year)

Los filtros date_from / date_to ya existen y se mantienen.
El filtro month_year es alternativo/adicional a date_from/date_to.

No hay cambio de schema ni migración. Solo cambio en el router.

4. T3 — FRONTEND: EDICIÓN DE TRANSACCIONES
=============================================================================

Archivo: frontend/src/pages/Transactions.tsx

El backend ya tiene PUT /api/transactions/{id}.
El api/transactions.ts ya exporta updateTransaction(id, data).

Cambios en la tabla:
  - Columna "Acciones" actualmente solo tiene "Eliminar".
  - Agregar botón "Editar" antes de "Eliminar".

Al hacer click en Editar:
  - Abrir el mismo Modal existente pero en modo edición.
  - Pre-cargar todos los campos del formulario con los datos de la transacción.
  - El título del modal cambia a "Editar Transacción".
  - El botón de guardar llama a updateTransaction(editingId, data) en lugar
    de createTransaction(data).
  - Al éxito: cerrar modal, refrescar tabla.

Estado adicional necesario:
  const [editingTx, setEditingTx] = useState<any | null>(null);
  // null = modo crear, objeto = modo editar

Lógica handleSave:
  if (editingTx) {
    await updateTransaction(editingTx.id, { ...form fields });
  } else {
    await createTransaction({ ...form fields });
  }

Al cerrar el modal: resetear editingTx a null y limpiar el formulario.

NOTA: El campo instrument_id NO debe ser editable en modo edición — mostrar
el nombre del instrumento como texto estático, no como selector. Cambiar el
instrumento de una transacción existente rompería la lógica de recálculo de
posiciones. Si el usuario necesita cambiar el instrumento, debe eliminar y
recrear la transacción.

5. T4 — FRONTEND: COMBOBOX CON BÚSQUEDA PARA SELECTOR DE INSTRUMENTO
=============================================================================

El selector de instrumento aparece en DOS lugares:
  a) El formulario de nueva/edición de transacción (campo "Instrumento")
  b) El filtro de instrumento en la barra de filtros

Crear componente reutilizable:
  frontend/src/components/ui/InstrumentCombobox.tsx

Props:
  value: number | ''
  onChange: (id: number | '') => void
  instruments: Array<{ id: number; name: string; custodian: string }>
  placeholder?: string        // default: "Buscar instrumento..."
  disabled?: boolean

Implementación con shadcn/ui Command + Popover:
  - Botón trigger que muestra el nombre del instrumento seleccionado,
    o el placeholder si ninguno seleccionado.
  - Al hacer click: abrir Popover con un Command (input de búsqueda +
    lista de resultados).
  - Filtrado: case-insensitive sobre name y custodian.
  - Cada ítem muestra: nombre del instrumento (bold) + custodian (gris, más pequeño).
  - Selección: al hacer click en un ítem, cerrar popover y llamar onChange.
  - Opción de limpiar: si hay valor seleccionado, mostrar ícono X para
    deseleccionar (llama onChange con '').
  - Máximo 200px de alto en la lista, scrollable.
  - Ancho del popover: mismo ancho que el trigger (w-full).

Usar este componente en:
  1. Formulario de transacción: reemplaza el <select> de instrument_id.
  2. Filtro de instrumento en la barra de filtros.

Verificar que shadcn/ui Command y Popover estén disponibles; si no,
instalar con: npx shadcn-ui@latest add command popover
