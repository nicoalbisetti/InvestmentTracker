1. RESUMEN DE LA FUNCIONALIDAD
=============================================================================

Agregar en la página Settings → tab "Catálogo de Instrumentos" un botón
"+ Nuevo Instrumento" que abre un modal con formulario completo para crear
un instrumento manualmente.

El instrumento creado queda disponible de inmediato en la tabla del catálogo
y en la tabla de Posiciones.

Opcionalmente, el usuario puede ingresar un saldo inicial en BRL junto con el
período (mes/año) al que corresponde. El backend calcula automáticamente el
`balance_usd` usando la cotización USD/BRL registrada para ese período en la
tabla `quotes`. Si no hay cotización disponible para ese mes, se crea la
posición igual pero con `balance_usd = null` y se devuelve un warning.

Esta funcionalidad es útil para pre-registrar instrumentos antes de importar
datos (flujo XP International), para dar de alta activos que no provienen de
ningún extrato importable, o para cargar posiciones históricas de forma manual.

2. BACKEND — NUEVO ENDPOINT
=============================================================================

### Archivo: backend/app/routers/instruments.py

Agregar endpoint:

  POST /api/instruments

Body (JSON):
  {
    "name":           string,        // requerido
    "custodian":      string,        // requerido
    "type":           string,        // requerido — ver valores válidos abajo
    "currency":       string,        // requerido — "BRL" | "USD"
    "status":         string,        // requerido — "activo" | "cerrado" | "sin_datos"
    "location":       string,        // requerido — "brasil" | "exterior"
    "liquidity":      string | null, // opcional — "D+0", "D+2", "D+30", etc.
    "maturity_date":  string | null, // opcional — "YYYY-MM-DD"
    "index_type":     string | null, // opcional — "PREFIXADO" | "IPCA" | "DI" | "SELIC"
    "asset_class":    string | null, // opcional — ver valores válidos abajo

    // Saldo inicial — todos opcionales, pero si se envía balance_brl
    // también se debe enviar initial_period
    "balance_brl":    float | null,  // opcional — saldo inicial en BRL
    "initial_period": string | null, // "YYYY-MM" — requerido si balance_brl presente
  }

Valores válidos para `type`:
  "renta_fija" | "accion" | "fii" | "fundo" | "previdencia" |
  "prestamos" | "saving" | "fgts" | "outro"

Valores válidos para `asset_class` (solo relevante cuando type="renta_fija"):
  "CDB" | "CRI" | "CRA" | "DEB" | "LCA" | "LCI" | "LIG" | "TD" |
  "FUNDO_CREDITO" | null

Lógica:
  1. Validar que `name` y `custodian` no estén vacíos.
  2. Si `balance_brl` está presente y `initial_period` está ausente → 422
     con mensaje: "Se requiere el período cuando se provee un saldo inicial."
  3. Verificar que no exista ya un instrumento con el mismo (name, custodian).
     Si existe → 409 Conflict con mensaje:
     "Ya existe un instrumento con ese nombre y custodio."
  4. Dentro de una transacción de DB atómica:
     a. Crear el Instrument con todos los campos provistos.
        Campos no enviados → defaults del modelo.
     b. Si `balance_brl` está presente:
        i.  Normalizar `initial_period` al día 1 del mes:
              year, month = map(int, initial_period.split("-"))
              pos_date = date(year, month, 1)
        ii. Buscar la cotización USD/BRL para ese período:
              quote = db.query(Quote).filter_by(date=pos_date).first()
        iii. Calcular balance_usd:
               Si quote y quote.usd_brl:
                 balance_usd = round(balance_brl / quote.usd_brl, 2)
                 usd_rate    = quote.usd_brl
               Si no hay cotización:
                 balance_usd = None
                 usd_rate    = None
                 agregar warning: "Sin cotización USD/BRL para {initial_period}
                                   — balance_usd no calculado"
        iv. Crear MonthlyPosition:
              instrument_id = <nuevo id>
              date          = pos_date
              balance_brl   = payload.balance_brl
              balance_usd   = balance_usd   (puede ser None)
              usd_rate      = usd_rate      (puede ser None)
        v.  Actualizar cache del instrumento:
              instrument.current_balance_brl = payload.balance_brl
     c. Commit.
  5. Retornar:
     {
       "id": <id>,
       "name": <nombre>,
       "custodian": <custodio>,
       "position_created": true | false,
       "balance_usd": <valor calculado> | null,
       "warnings": ["Sin cotización USD/BRL para 2026-03 — balance_usd no calculado"],
       "message": "Instrumento creado correctamente"
     }

Errores:
  - 400: name o custodian vacíos
  - 409: duplicado (name + custodian)
  - 422: tipo inválido, currency inválida, balance_brl sin initial_period,
         initial_period con formato incorrecto (debe ser "YYYY-MM")

### 3.5 Función handleCreateInstrument

```typescript
const handleCreateInstrument = async () => {
  if (!createForm.name.trim() || !createForm.custodian.trim()) {
    setCreateError('Nombre y custodio son obligatorios.');
    return;
  }
  const hasSaldo = createForm.balance_brl !== '' && Number(createForm.balance_brl) > 0;
  if (hasSaldo && !createForm.initial_period) {
    setCreateError('El período es requerido cuando se ingresa un saldo.');
    return;
  }
  setCreateSaving(true);
  setCreateError(null);
  try {
    const result = await createInstrument({
      name: createForm.name.trim(),
      custodian: createForm.custodian.trim(),
      type: createForm.type,
      currency: createForm.currency,
      status: createForm.status,
      location: createForm.location,
      liquidity: createForm.liquidity || undefined,
      maturity_date: createForm.maturity_date || undefined,
      index_type: createForm.index_type || undefined,
      asset_class: createForm.asset_class || undefined,
      balance_brl: hasSaldo ? Number(createForm.balance_brl) : undefined,
      initial_period: hasSaldo ? createForm.initial_period : undefined,
    });
    setShowCreate(false);
    setCreateForm(defaultCreateForm);
    if (result.warnings?.length > 0) {
      setCreateWarning(result.warnings[0]);
      setTimeout(() => setCreateWarning(null), 5000);
    }
    load(); // recargar tabla del catálogo
  } catch (err: any) {
    const msg = err.response?.data?.detail || err.message || 'Error al crear el instrumento.';
    setCreateError(msg);
  } finally {
    setCreateSaving(false);
  }
};
```

Agregar al estado local:
```typescript
const [createWarning, setCreateWarning] = useState<string | null>(null);
```

Al cerrar el modal (onClose):
  - Resetear `createForm` a `defaultCreateForm`
  - Limpiar `createError`
  - NO limpiar `createWarning` (debe seguir visible tras el cierre)

5. CRITERIOS DE ACEPTACIÓN
=============================================================================

1. El botón "+ Nuevo Instrumento" es visible en el tab "Catálogo de
   Instrumentos" de Settings, a la derecha del contador.

2. El modal se abre con todos los campos en sus valores default
   (type=renta_fija, currency=BRL, status=activo, location=brasil).
   Los campos de saldo inicial están vacíos.

3. Intentar guardar con nombre vacío o custodio vacío muestra el error
   de validación sin llegar al backend.

4. Intentar guardar con balance_brl completado pero initial_period vacío
   muestra el error de validación en el cliente, sin llegar al backend.

5. Crear un instrumento sin saldo:
   a. Se crea con current_balance_brl = null.
   b. Aparece en el catálogo pero NO en la tabla de Posiciones con filtro
      status=activo (a menos que el filtro lo incluya).
   c. El modal se cierra y el formulario se resetea.

6. Crear un instrumento con saldo BRL + período con cotización disponible:
   a. Se crea la MonthlyPosition con balance_brl y balance_usd calculado.
   b. El instrumento aparece en Posiciones con el saldo correcto.
   c. No se muestra ningún warning.

7. Crear un instrumento con saldo BRL + período SIN cotización disponible:
   a. Se crea la MonthlyPosition con balance_brl y balance_usd = null.
   b. El modal se cierra y aparece un warning amarillo visible por 5 segundos.

8. Crear un instrumento con (name, custodian) duplicado retorna 409 y
   el modal muestra el mensaje sin cerrarse.

9. Las filas de Asset Class e Indexador solo aparecen cuando type === "renta_fija".

10. Cambiar currency a "USD" setea location a "exterior" automáticamente.
    Cambiar location a "exterior" setea currency a "USD" automáticamente.

11. El botón "Crear Instrumento" queda deshabilitado durante el request.

12. TASKS.md se crea antes de empezar el código y se mantiene actualizado.
