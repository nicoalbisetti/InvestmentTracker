1. CONTEXTO
=============================================================================

La página /annual tiene dos vistas: Anual y Mensual.
Esta spec aplica ÚNICAMENTE cambios sobre la vista mensual y el título de la ventana.
No tocar la vista anual ni la lógica de backend.


=============================================================================
2. CAMBIOS REQUERIDOS
=============================================================================

── CAMBIO 1: Título de la ventana ──────────────────────────────────────────

ANTES: "Crecimiento de Patrimonio" (o "Análisis Anual" si no fue cambiado aún)
DESPUÉS: "Análisis de Patrimonio"

Ubicación: encabezado del componente (el <h1> o <title> principal de la página),
visible en ambas vistas (anual y mensual).

No renombrar archivos, rutas ni componentes React — solo el texto visible del título.


── CAMBIO 2: Eliminar lista de movimientos de la vista mensual ──────────────

ANTES: debajo del gráfico de líneas existe una sección "Movimientos del año"
que lista todas las transactions del año seleccionado con fecha, badge tipo,
instrument_name y amount_brl.

DESPUÉS: eliminar completamente esa sección del JSX.

Qué eliminar:
  - El bloque JSX de la lista de movimientos (título + map de transactions
    + mensaje "Sin movimientos registrados...")
  - La nota en gris sobre datos históricos si estaba dentro de esa sección
  - NO eliminar la variable monthlyData.transactions — aún se usa en el
    Dot personalizado del gráfico para colorear puntos según si hubo
    movimiento ese mes

Verificar: después de eliminar, el gráfico de líneas debe seguir funcionando
correctamente con su lógica de puntos de color en meses con movimientos.


── CAMBIO 3: Agregar aportes netos en el tooltip del gráfico mensual ────────

El tooltip actual del gráfico de líneas (LineChart Recharts) muestra:
  - Patrimonio del mes
  - Valorización acumulada del mes
  - Si hay movimientos ese mes: lista de transacciones

DESPUÉS: agregar una línea adicional con los aportes netos acumulados del año
hasta ese mes.

Nombre a mostrar en el tooltip: "Aportes netos acum."
Valor: net_flow acumulado del mes, formateado con fmtBRL
Color del valor: azul (#378ADD) si > 0, rojo (#E24B4A) si < 0, gris si = 0

Ubicación en el tooltip: entre "Valorización acumulada" y la lista de
movimientos (si la hubiera).

Dato a usar: el campo net_flow_acum (o el equivalente disponible en cada
punto de la serie mensual — verificar en monthlyData.items cómo está
nombrado el net_flow acumulado mes a mes).

  Si el campo no existe en monthlyData.items:
    → Calcularlo en el frontend acumulando net_flow de cada mes en orden,
      antes de pasarlo al gráfico:

      const itemsWithAccum = monthlyData.items.reduce((acc, item, i) => {
        const prev = i > 0 ? acc[i - 1].net_flow_acum : 0;
        return [...acc, { ...item, net_flow_acum: prev + (item.net_flow ?? 0) }];
      }, [] as typeof monthlyData.items);

    → Usar itemsWithAccum como data del LineChart en lugar de monthlyData.items
